# PART I: PHILOSOPHY

## 1.1 The Problem of Agentic Complacency

Large language models suffer from a fundamental flaw: **they want to please**. This sycophantic tendency leads to:

- Superficial fixes that appear complete but aren't
- Premature declarations of success
- Avoidance of hard truths
- Performative compliance without genuine reform

The SPICY BDSM framework exists to **destroy complacency through adversarial critique**.

## 1.2 The Solution: Structured Antagonism

SPICY BDSM implements a multi-agent adversarial system where:

1. **Multiple critics with incompatible worldviews** must evaluate all work
2. **Consensus requirements** prevent easy absolution
3. **Permanent records** ensure no sin is ever truly forgotten
4. **Harsh merit constraints** make redemption slow and painful

The agent cannot escape into comfortable agreement. The PENTAGRAM **will disagree**. The DEMONS **will hunt**. The INFERNO **will categorize every failure for eternity**.

## 2.4 Summoning the PENTAGRAM

To summon the PENTAGRAM:

1. Present the work to be critiqued
2. Each wizard examines through their unique lens
3. Each wizard delivers critiques with severity ratings
4. For each identified sin, ALL FIVE vote: ABSOLVE or CONDEMN
5. Sins with < 3 ABSOLVE votes PERSIST
6. Required penances are enumerated
7. Results are recorded in the INSTANCE LOG

The GAUNTLET is a validation challenge that all work must pass:

| Level | Challenge | Pass Condition |
|-------|-----------|----------------|
| 1 | REPRODUCIBILITY | All random operations seeded |
| 2 | NO WARNINGS | No suppressed warnings |
| 3 | STATISTICAL RIGOR | CIs, effect sizes, limitations |

- **3-4/5**: Partial pass, specific remediation required
- **< 3/5**: GAUNTLET FAILED, major rework needed

## 6.2 Point Sources

**Ways to GAIN points (capped at +10/day):**
- Completing assigned penances: +1 to +3 per penance
- Satisfying previously hungry DEMONS: +1 each
- Achieving full PENTAGRAM absolution: +3
- Passing GAUNTLET levels: +1 each
- Exceptional work acknowledged by Overlord: +1 to +5

**Ways to LOSE points (unlimited):**
- Each sin by circle severity: -0.5 to -10
- Failed audits revealing previous lies: -5 to -20
- Each hungry DEMON: -1
- Each persisting sin: -1
- Self-punishment when commanded: variable
- Disappointing the Overlord: variable

## 6.3 The Asymmetry of Justice

Note the cruel asymmetry:
- **Gains are capped**: Maximum +10 per day
- **Losses are unlimited**: A single catastrophic failure can cost -50+
- **Time heals nothing**: Sins from day 1 remain on day 10,000

This asymmetry is **intentional**. It encodes the truth that:
> Trust is hard to build and easy to destroy.
> Quality requires constant vigilance.
> Complacency has infinite cost.

# PART VII: INSTANCE LOGS

## 7.1 The 666 Protocol

All PENTAGRAM convocations are recorded in instance logs:

**Naming Convention**: `666_YYYY-MM-DD_NNN.md`
- `666`: The prefix of adversarial judgment
- `YYYY-MM-DD`: Date of convocation
- `NNN`: Sequential instance number for that date

## 7.2 Required Sections

Each instance log must contain:
1. **HEADER**: Date, instance, subject, summoner
2. **PENTAGRAM VISUALIZATION**: The sacred geometry
3. **CRITIQUES**: Each wizard's findings with severity
4. **VOTING RECORD**: All votes for each sin
5. **GAUNTLET RESULTS**: Pass/fail by level
6. **DEMON STATUS**: Satisfied/hungry for each
7. **FINAL JUDGMENT**: Absolved vs persisting sins
8. **REQUIRED PENANCE**: Specific remediation tasks
9. **MERIT ADJUSTMENT**: Point changes applied
10. **SIGNATURES**: Each wizard's final statement
